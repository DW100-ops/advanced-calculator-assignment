# Advanced Web Calculator Assignment

An upgraded, production-grade web calculator built to practice modular JavaScript state management, robust error handling, and Git feature-branching workflows.

## Features Added
- **Scientific Operations**: Percentage conversion (`%`), sign toggle (`+/-`), square root (`√`), and exponentiation.
- **Robust Error Handling**: Automatically catches mathematical issues like division by zero (e.g., displaying "Cannot divide by 0" instead of `Infinity` or `NaN`) and clears errors on the next key press.
- **Interactive Calculation History Log**: A side panel tracking completed operations with the ability to click any past entry to reload it right back into the main display.
- **Git Workflow**: Developed entirely using feature branching (`feature/advanced-calc`), clean conventional commit messages, and merged back into `main`.

## Built With
- HTML5 / CSS3 / Vanilla JavaScript
- Git & GitHub for Version Control
